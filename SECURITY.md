# Security policy

Gyrai is a governance and audit tool, so we take reports about its own security seriously.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Email **jrs@consultant.works** with:

- a description of the issue and its impact,
- steps to reproduce, and the version or commit you tested,
- any suggested fix.

We aim to acknowledge reports within five business days and to keep you informed as we investigate. Please give us reasonable time to fix an issue before disclosing it publicly.

## Supported versions

Gyrai is in early development (0.x). Only the latest release receives security fixes.

## Scope notes

- Never include real credentials, tenant identifiers or customer data in a report or a pull request.
- The sample data in `samples/` is fictional.
